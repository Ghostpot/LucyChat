# ЛюсиЧат

Чат эфира для Windows: Twitch, YouTube, VK Видео, GoodGame, Rutube, Steam. Голос, окно для OBS и ответы Люси в чат Twitch.

Сайт: [ghostpot.ru](https://ghostpot.ru)

**Как скачать, запустить и кого подключить — [инструкция в картинках](docs/KAK.md).**

Сборка: .NET 8, Windows x64.

```
dotnet publish -c Release
```

Голос Silero и маленькая модель Люси качаются из программы один раз. В репозиторий они не входят.
