# ЛюсиЧат

Чат эфира для Windows: Twitch, YouTube, VK Видео, GoodGame, Rutube, Steam. Голос, окно для OBS и ответы Люси.

Сайт: [ghostpot.ru](https://ghostpot.ru)

Как запускать и что нажимать — в [README.txt](README.txt).

Сборка: .NET 8, Windows x64.

```
dotnet publish -c Release
```

Голос Silero и маленькая модель Люси качаются из программы один раз. В репозиторий они не входят.
